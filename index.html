Walmart Mobile UX Study Flow Selection

Walmart Canada Mobile Support A/B Study

Evaluating user journeys for connecting with a live customer care agent following a damaged item delivery. Course: MMDD 231 – Contemporary Web Design 2 • Student: Maryam Nazargol

Testing Scenario

“You received a damaged item from a recent Walmart order. Starting from the signed-in Walmart home screen, find a way to get help and join the queue for a live customer-service agent.”

* Note: This instruction is not displayed inside the Walmart mobile UI so test participants discover their route naturally.

Version A • Experimental Flow

Order-First Support

The customer locates the delivered order in Purchase History, requests support directly within the order details, and flows into the queue with order context automatically attached.

1 Shared Home Screen (Signed In)
2 Account Navigation → Orders
3 Purchase History → Select Crib Order
4 Order Details → "Get help with this item"
5 Choose Issue → "Damaged item"
6 Support Handoff → Chat with us
7 Joined Queue (Context attached)
Version B • Baseline Flow

Support-First Flow

The customer enters Help Centre via Account, selects the damaged-item problem, connects the delivered order from recent purchases, and enters the queue.

1 Shared Home Screen (Signed In)
2 Account → Lower Help Centre Entry
3 Help Centre → Contact Us
4 Guided Category → "Damaged item"
5 Select Relevant Order → Continue
6 Order Connected Confirmation
7 Joined Queue (Identical End Screen)

Usability Test Briefing

“You received a damaged item from a recent Walmart order. Starting from the signed-in Walmart home screen, find a way to get help and join the queue for a live customer-service agent.”

A/B Testing Comparison Variables:

  • Version A (Order-First): User enters Account → Purchase History → Selects Delivered Crib → "Get help with this item" → Damaged item → Support queue.
  • Version B (Support-First): User enters Account → Help Centre → Contact us → Damaged item issue → Links crib order → Support queue.
  • Key Usability Improvements Addressed:
    • Human support discoverability without buried policy reading (Issue 1)
    • Reduced branching & unnecessary decision taps (Issue 2)
    • No misleading 00:00 countdown clock; realistic position & wait (Issue 3)
    • 390px viewport integrity without horizontal scrolling (Issue 4)
    • Automatic order & issue context continuity (Issue 5)
